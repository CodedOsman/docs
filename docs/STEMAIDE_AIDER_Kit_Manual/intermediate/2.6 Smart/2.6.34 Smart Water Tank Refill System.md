# Project 2.6.34: Smart Water Tank Refill System

**Intermediate Embedded Systems Project Using Raspberry Pi Pico 2 W and MicroPython**

---
## Overview

This project builds a water tank refill controller that starts filling when one water-level sensor reports a low level and stops when the same sensor reports a full level.

Students will use one analog water-level sensor, a relay-controlled pump, a status LED, and a buzzer for timeout alerts.

The final system should start the pump below the low threshold, stop it at the full threshold, and shut down safely if filling takes too long.

## Step-by-Step Assembly

### Step 1: Place the Raspberry Pi Pico 2W
Place the Raspberry Pi Pico 2W on the breadboard so it sits across the center gap. Keep the USB port facing outward so you can easily connect it to your computer.

### Step 2: Position the Water-Level Sensor
Place the water-level sensor in the test tank so it can measure the changing water level. Keep its electronics above the water line and identify its VCC, GND, and AOUT pins before wiring.

### Step 3: Connect the Water-Level Sensor
Connect sensor VCC to **3.3V**, GND to Pico GND, and AOUT to **GPIO 26**. Use a 3.3V-safe analog output.

### Step 4: Place and Wire the Relay Module
Identify relay VCC, GND, IN, COM, NO, and NC. Connect relay IN to **GPIO 15**. Power the relay module from the supply required by its label. Connect relay GND to Pico GND and to the external pump supply GND where shared grounding is required.

### Step 5: Place the Status LED
Place the status LED on the breadboard. Connect its long leg through a 220? resistor to **GPIO 16**. Connect its short leg to **GND**.

### Step 6: Place the Buzzer
Place the buzzer on the breadboard and identify its positive (+) and negative (-) pins. Connect the buzzer positive pin to **GPIO 17** and the buzzer negative pin to **GND**.

### Step 7: Wire the Pump Through the Relay
Connect the external pump supply positive wire to relay **COM**. Connect relay **NO** to the pump positive lead. Connect the pump negative lead to the external pump supply negative wire.

## Full Project Code

After completing and checking the circuit connections, open Thonny IDE. Copy and paste the code below into a new file, or upload the project file to the Raspberry Pi Pico 2 W, then run it from Thonny.

```python
from machine import ADC, Pin
import time

RELAY_ON = 0
RELAY_OFF = 1
MAX_FILL_S = 60
LOW_LEVEL = 35
FULL_LEVEL = 75

water_sensor = ADC(26)
relay = Pin(15, Pin.OUT)
status_led = Pin(16, Pin.OUT)
buzzer = Pin(17, Pin.OUT)

filling = False
fill_started = 0

relay.value(RELAY_OFF)
status_led.value(0)
buzzer.value(0)


def water_level_percent():
    return int((water_sensor.read_u16() / 65535) * 100)


def alarm_burst():
    for _ in range(2):
        buzzer.on()
        time.sleep(0.15)
        buzzer.off()
        time.sleep(0.15)


def start_fill(reason):
    global filling, fill_started
    relay.value(RELAY_ON)
    status_led.value(1)
    filling = True
    fill_started = time.time()
    print("Pump ON:", reason)


def stop_fill(reason):
    global filling
    relay.value(RELAY_OFF)
    status_led.value(0)
    filling = False
    print("Pump OFF:", reason)


print("Smart water tank refill system ready")

while True:
    level = water_level_percent()
    now = time.time()

    if filling and level >= FULL_LEVEL:
        stop_fill("tank reached full threshold")
    elif (not filling) and level <= LOW_LEVEL:
        start_fill("water level below low threshold")
    elif filling and (now - fill_started) >= MAX_FILL_S:
        stop_fill("maximum fill time exceeded")
        alarm_burst()
    else:
        print("WaterLevel:{}% Status:{}".format(level, "REFILLING" if filling else "MONITORING"))

    time.sleep(1)
```

## How the Code Works

| Code Section | What It Does | Why It Matters |
|--------------|--------------|----------------|
| `water_level_percent()` | Converts the sensor's ADC reading to a percentage | Makes the changing water-level value easy to use and understand |
| `LOW_LEVEL` and `FULL_LEVEL` | Define the single sensor's start and stop thresholds | The pump starts low and stops when the same sensor reports full |
| `MAX_FILL_S` | Stops the pump if filling takes too long | A timeout can prevent dry running or overflow from a failed sensor |
| `alarm_burst()` | Uses the buzzer only for a timeout fault | Students learn that alarms should signal problems, not normal operation |

---

## Expected Result

When the water level is below `LOW_LEVEL`, the pump should start and the LED should turn on. When the same sensor reports a level at or above `FULL_LEVEL`, the pump should stop. If filling takes too long, the system should stop the pump and beep the buzzer.

## Troubleshooting

| Problem | Possible cause | Solution |
|---------|----------------|----------|
| The pump never starts | The sensor reading is above `LOW_LEVEL`, or the relay is miswired | Print the water-level percentage and verify `RELAY_ON` / `RELAY_OFF` |
| The pump never stops | `FULL_LEVEL` is too high or the sensor reading does not increase | Check the sensor position and lower `FULL_LEVEL` after testing |
| The buzzer alarms immediately | `MAX_FILL_S` is too short | Increase `MAX_FILL_S` after measuring a normal refill time |
| The timeout always trips | The water path is blocked or the tank cannot reach `FULL_LEVEL` | Inspect the tubing and pump flow, then verify the sensor reading |
