## Wiring the circuit

**Step 1:** Connect the flame sensor:

- Connect the **DO** (Digital Output) pin to **GPIO 2** on the ESP32 board.
- Connect **VCC** to the power rail specified for the module.
- Connect **GND** to the ground rail.

![Circuit wiring step 1](../../../assets/project-files/expert/4.1.8_Smart_Fire_Safety__Alarm_System/circuit_1.png)

**Step 2:** Connect the relay module:

- Connect **IN** (Signal) to **GPIO 21** on the ESP32 board.
- Connect **VCC** to the power rail specified for the module.
- Connect **GND** to the ground rail.
- Connect relay **COM** to the load supply.
- Connect either **NO** or **NC** to the load, according to the required switching behavior; do not connect both terminals to the load.

![Circuit wiring step 2](../../../assets/project-files/expert/4.1.8_Smart_Fire_Safety__Alarm_System/circuit_2.png)

**Step 3:** Connect the buzzer:

- Connect the positive (+) pin to **GPIO 22**.
- Connect the negative (−) pin to **GND**.

![Circuit wiring step 3](../../../assets/project-files/expert/4.1.8_Smart_Fire_Safety__Alarm_System/circuit_3.png)

**Step 4:** Connect the red LED:

- Connect the anode (positive leg) to **GPIO 27** through a **220Ω resistor**.
- Connect the cathode (negative leg) to **GND**.

Check all signal, power, ground, and polarity connections before connecting the USB cable.


_Make sure to connect the Micro USB cable to the ESP32 board._

![Circuit wiring step 4](../../../assets/project-files/expert/4.1.8_Smart_Fire_Safety__Alarm_System/circuit_4.png)

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
// Project 63: Smart Fire Safety & Alarm System
const int flamePin = 2;
const int relayPin = 21;
const int buzzerPin = 22;
const int ledPin = 27;

void setup() {
  pinMode(flamePin, INPUT);
  pinMode(relayPin, OUTPUT);
  pinMode(buzzerPin, OUTPUT);
  pinMode(ledPin, OUTPUT);
  digitalWrite(relayPin, LOW);
  digitalWrite(buzzerPin, LOW);
  digitalWrite(ledPin, LOW);
}

void loop() {
  if (digitalRead(flamePin) == LOW) {
    digitalWrite(relayPin, HIGH);
    digitalWrite(ledPin, HIGH);
    digitalWrite(buzzerPin, HIGH);
    delay(100);
    digitalWrite(buzzerPin, LOW);
    delay(100);
  } else {
    digitalWrite(relayPin, LOW);
    digitalWrite(ledPin, LOW);
    digitalWrite(buzzerPin, LOW);
    delay(200);
  }
}
```
