## Wiring the circuit

**Step 1:** Connect the BME280:

- Connect **VCC** to **3.3V**
- Connect **GND** to **GND**
- Connect **SDA** to **GPIO 21**
- Connect **SCL** to **GPIO 22**.

![Circuit wiring step 1](../../../assets/project-files/expert/4.1.21_Environmental_Comfort_Index_Meter/circuit_1.png)

**Step 2:** Connect the MAX7219 8x8 matrix:

- Connect **DIN** to **GPIO 23**
- Connect **CLK** to **GPIO 18**
- Connect **CS/LOAD** to **GPIO 5**
- Connect **VCC** to **3.3V**
- Connect **GND** to common **GND**.

![Circuit wiring step 2](../../../assets/project-files/expert/4.1.21_Environmental_Comfort_Index_Meter/circuit_2.png)

**Step 3:** Connect the Active buzzer:

- Connect **signal/+** to **GPIO 25**.
- Connect **GND/-** to common **GND**.

![Circuit wiring step 3](../../../assets/project-files/expert/4.1.21_Environmental_Comfort_Index_Meter/circuit_3.png)


## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Install the **Adafruit BME280**, **Adafruit Unified Sensor**, and **LedControl** libraries from Arduino IDE Library Manager, then enter and upload this complete program.

```cpp
#include <Wire.h>
#include <Adafruit_BME280.h>
#include <LedControl.h>

// Project 76: Environmental Comfort Index Meter
const int matrixDataPin = 23;
const int matrixClockPin = 18;
const int matrixLoadPin = 5;
const int buzzerPin = 25;
const byte comfortableFace[8] = {0x3C, 0x42, 0xA5, 0x81, 0xA5, 0x99, 0x42, 0x3C};
const byte uncomfortableFace[8] = {0x3C, 0x42, 0xA5, 0x81, 0x99, 0xA5, 0x42, 0x3C};

Adafruit_BME280 bme;
LedControl matrix(matrixDataPin, matrixClockPin, matrixLoadPin, 1);

void setup() {
  Serial.begin(9600);
  Wire.begin(21, 22);
  pinMode(buzzerPin, OUTPUT);
  digitalWrite(buzzerPin, LOW);
  matrix.shutdown(0, false);
  matrix.setIntensity(0, 5);
  matrix.clearDisplay(0);
  if (!bme.begin(0x76) && !bme.begin(0x77)) {
    Serial.println("BME280 not found at 0x76 or 0x77.");
    while (true) delay(100);
  }
  Serial.println("Project 76: Environmental Comfort Index Meter Initialized...");
}

void showFace(const byte face[8]) {
  for (int row = 0; row < 8; ++row) matrix.setRow(0, row, face[row]);
}

void loop() {
  const float temperatureC = bme.readTemperature();
  const float humidity = bme.readHumidity();
  const bool comfortable = temperatureC >= 18.0 && temperatureC <= 27.0 &&
                           humidity >= 30.0 && humidity <= 60.0;

  showFace(comfortable ? comfortableFace : uncomfortableFace);
  digitalWrite(buzzerPin, comfortable ? LOW : HIGH);
  Serial.print("Temperature: ");
  Serial.print(temperatureC, 1);
  Serial.print(" C | Humidity: ");
  Serial.print(humidity, 1);
  Serial.print(" % | Comfort: ");
  Serial.println(comfortable ? "comfortable" : "outside target range");
  delay(1000);
}
```

**Step 3:** Save your code. _See the [Getting Started](../../Getting Started/Arduino_IDE_Setup.md) section._

**Step 4:** Select the ESP32 board and port. See the [Getting Started](../../Getting Started/Arduino_IDE_Setup.md) section.

**Step 5:** Upload your code. See the [Getting Started](../../Getting Started/Arduino_IDE_Setup.md) section.
