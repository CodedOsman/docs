## Wiring the circuit

**Step 1:** Connect the HC-SR04 ultrasonic sensor:

- Connect **VCC** to ESP32 **5V/VIN**.
- Connect **GND** to **GND**.
- Connect **TRIG** to **GPIO 18**.
- Connect sensor **ECHO** to **GPIO 19**.


![Circuit wiring step 1](../../../assets/project-files/expert/4.1.11_Proximity_Warning_Radar/circuit_1.png)

**Step 2:** Connect the Active buzzer:

- Connect **signal/+** to **GPIO 21**.
- Connect **GND/-** to ESP32 **GND**.

![Circuit wiring step 2](../../../assets/project-files/expert/4.1.11_Proximity_Warning_Radar/circuit_2.png)

**Step 3:** Connect the Traffic light module:

- Connect **R** to **GPIO 25**
- Connect **Y** to **GPIO 26**
- Connect **G** to **GPIO 27**
- Connect module **GND** to ESP32 **GND**. 

![Circuit wiring step 3](../../../assets/project-files/expert/4.1.11_Proximity_Warning_Radar/circuit_3.png)


## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
// Project 66: Proximity Warning Radar
// Target Integration: HC-SR04 Ultrasonic + Active Buzzer + Traffic Light Module

const int trigPin = 18;
const int echoPin = 19;
const int redLed = 25;
const int yellowLed = 26;
const int greenLed = 27;
const int buzzer = 21;

void setup() {
  Serial.begin(9600);
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(redLed, OUTPUT);
  pinMode(yellowLed, OUTPUT);
  pinMode(greenLed, OUTPUT);
  pinMode(buzzer, OUTPUT);
  Serial.println("Project 66: Proximity Warning Radar Initialized...");
}

void loop() {
  long duration, distance;
  
  // Trigger sensor
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  
  // Read echo
  duration = pulseIn(echoPin, HIGH);
  distance = (duration / 2) / 29.1;

  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.println(" cm");

  // Logic control
  if (distance > 0 && distance < 10) {
    // Red Light + Buzzer
    digitalWrite(redLed, HIGH);
    digitalWrite(yellowLed, LOW);
    digitalWrite(greenLed, LOW);
    digitalWrite(buzzer, HIGH);
  } else if (distance >= 10 && distance < 25) {
    // Yellow Light
    digitalWrite(redLed, LOW);
    digitalWrite(yellowLed, HIGH);
    digitalWrite(greenLed, LOW);
    digitalWrite(buzzer, LOW);
  } else {
    // Green Light
    digitalWrite(redLed, LOW);
    digitalWrite(yellowLed, LOW);
    digitalWrite(greenLed, HIGH);
    digitalWrite(buzzer, LOW);
  }
  delay(200);
}
```
