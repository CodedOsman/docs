## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Connect the ESP32 board 5V pin to the breadboard's positive (+) power rail and the ESP32 board GND pin to the negative (-) power rail.

![power connection](../../../assets/project-files/expert/4.2.11_Interactive_Keypad_Calculator_Engine/circuit_1.png)

**Step 2:** Place the 4x4 Matrix Keypad on the breadboard.

  - Connect the 8 row and column pins to Digital Pins 18, 19, 12, 13, 5, 4, 15, and 2 respectively

![power connection](../../../assets/project-files/expert/4.2.11_Interactive_Keypad_Calculator_Engine/circuit_2.png)

**Step 3:** Place the IIC 1602 LCD on the breadboard.

  - Connect the VCC pin to the 5V power rail on the breadboard
  - Connect the GND pin to the ground rail on the breadboard
  - Connect the SDA pin to Analog GPIO 21
  - Connect the SCL pin to Analog GPIO 22

  ![power connection](../../../assets/project-files/expert/4.2.11_Interactive_Keypad_Calculator_Engine/circuit_3.png)


**Step 4:** Place the Active Buzzer on the breadboard.

  - Connect its positive (+) pin to Digital GPIO 33
  - Connect its negative (-) pin to the ground rail on the breadboard

![power connection](../../../assets/project-files/expert/4.2.11_Interactive_Keypad_Calculator_Engine/circuit_4.png)

**Step 5:** Ensure all components share a common GND connection, then verify all wiring before connecting the ESP32 board to your computer using the USB cable.

**Step 6:** After confirming that all connections are correct, connect the USB cable to the ESP32 board and the computer to power the circuit.

_Make sure to connect the Micro USB cable to the ESP32 board._

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
#include <Keypad.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

const byte ROWS = 4;
const byte COLS = 4;
char keys[ROWS][COLS] = {
  {'1','2','3','A'},
  {'4','5','6','B'},
  {'7','8','9','C'},
  {'*','0','#','D'}
};
byte rowPins[ROWS] = {18, 19, 12, 13};
byte colPins[COLS] = {5, 4, 15, 2};
Keypad keypad = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS);

LiquidCrystal_I2C lcd(0x27, 16, 2);
const int BUZZER_PIN = 33;

long valueA = 0;
long valueB = 0;
char operation = 0;
bool enteringB = false;

void beep() {
  digitalWrite(BUZZER_PIN, HIGH);
  delay(40);
  digitalWrite(BUZZER_PIN, LOW);
}

void setup() {
  Serial.begin(9600);
  pinMode(BUZZER_PIN, OUTPUT);
  lcd.init();
  lcd.backlight();
  lcd.print("Calculator Ready");
}

void loop() {
  char key = keypad.getKey();
  if (!key) return;

  beep();

  if (key >= '0' && key <= '9') {
    if (!enteringB) {
      valueA = valueA * 10 + (key - '0');
    } else {
      valueB = valueB * 10 + (key - '0');
    }
  } else if (key == 'A') {
    operation = '+';
    enteringB = true;
  } else if (key == 'B') {
    operation = '-';
    enteringB = true;
  } else if (key == 'C') {
    operation = '*';
    enteringB = true;
  } else if (key == 'D') {
    operation = '/';
    enteringB = true;
  } else if (key == '*') {
    valueA = 0;
    valueB = 0;
    operation = 0;
    enteringB = false;
  } else if (key == '#') {
    long result = 0;
    if (operation == '+') result = valueA + valueB;
    if (operation == '-') result = valueA - valueB;
    if (operation == '*') result = valueA * valueB;
    if (operation == '/' && valueB != 0) result = valueA / valueB;

    lcd.clear();
    lcd.setCursor(0, 0);
    lcd.print("Result:");
    lcd.setCursor(0, 1);
    lcd.print(result);
    delay(300);

    valueA = 0;
    valueB = 0;
    operation = 0;
    enteringB = false;
    return;
  }

  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print(valueA);
  if (operation) {
    lcd.print(operation);
    lcd.print(valueB);
  }
}
```
