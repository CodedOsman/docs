## Building the circuit

Things Needed:

- Arduino Uno Core Board
- XY Joystick Module
- RGB 3-Color Module
- 8x8 Dot Matrix Display
- USB Cable & Jumper Wires

## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Connect the Arduino 5V pin to the breadboard's positive (+) power rail and the Arduino GND pin to the negative (-) power rail.

**Step 2:** Place the XY Joystick Module on the breadboard.
  - Connect the VCC pin to the 5V power rail on the breadboard
  - Connect the GND pin to the ground rail on the breadboard
  - Connect the VRx pin to Analog Pin A0
  - Connect the VRy pin to Analog Pin A1
  - Connect the SW (switch) pin to Digital Pin 2

**Step 3:** Place the RGB 3-Color Module on the breadboard.
  - Connect the Red, Green, and Blue pins to Digital Pins 5, 6, and 9 respectively through 220Ω resistors
  - Connect the common pin to the ground rail on the breadboard (Common Cathode) or the 5V power rail on the breadboard (Common Anode)

**Step 4:** Place the 8x8 Dot Matrix Display on the breadboard.
  - Connect the VCC pin to the 5V power rail on the breadboard
  - Connect the GND pin to the ground rail on the breadboard
  - Connect the DIN pin to Digital Pin 11
  - Connect the CS pin to Digital Pin 10
  - Connect the CLK pin to Digital Pin 13

**Step 5:** Ensure all components share a common GND connection, then verify all wiring before connecting the Arduino Uno to your computer using the USB cable.

![Components on breadboard](../../../assets/coder_pro/expert/expert_II/4.2.12_Project_102_Joystick_Controlled_RGB_Matrix_Palette/image_1.png)

**Step 6:** After confirming that all connections are correct, connect the USB cable to the Arduino Uno board and the computer to power the circuit.

_Make sure to connect the Arduino USB cable to the Arduino board._

// Define pins
const int VRx = A0;
const int VRy = A1;
const int SW = 2;
const int redPin = 5;
const int greenPin = 6;
const int bluePin = 9;

void setup() {
  pinMode(VRx, INPUT);
  pinMode(VRy, INPUT);
  pinMode(SW, INPUT_PULLUP);
  pinMode(redPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
  pinMode(bluePin, OUTPUT);
  Serial.begin(9600);
  Serial.println("Project 102: Joystick Controlled RGB Matrix Palette Hardware Online");
}

void loop() {
  // Read joystick values
