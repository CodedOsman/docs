## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Connect the ESP32 board 5V pin to the breadboard's positive (+) power rail and the ESP32 board GND pin to the negative (-) power rail.

![power connection](../../../assets/project-files/expert/4.2.17_Multi_Button_Remote_Fan_Speed_Switcher/circuit_1.png)

**Step 2:** Place the IR Receiver on the breadboard.

  - Connect the VCC pin to the 5V power rail on the breadboard
  - Connect the GND pin to the ground rail on the breadboard
  - Connect the OUT/Signal pin to Digital GPIO 25

![power connection](../../../assets/project-files/expert/4.2.17_Multi_Button_Remote_Fan_Speed_Switcher/circuit_2.png)

**Step 3:** Place the DC motor on the breadboard without a separate driver board.

  - Connect the motor positive lead to the 5V power rail on the breadboard
  - Connect the motor negative lead to Digital GPIO 23
  - Keep the ESP32 ground and the motor power ground connected together

![power connection](../../../assets/project-files/expert/4.2.17_Multi_Button_Remote_Fan_Speed_Switcher/circuit_3.png)

**Step 4:** Ensure all components share a common GND connection, then verify all wiring before connecting the ESP32 board to your computer using the USB cable.

![power connection](../../../assets/project-files/expert/4.2.17_Multi_Button_Remote_Fan_Speed_Switcher/circuit_4.png)

**Step 5:** After confirming that all connections are correct, connect the USB cable to the ESP32 board and the computer to power the circuit.

_Make sure to connect the Micro USB cable to the ESP32 board._

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
#include <IRremote.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

const int IR_PIN = 25;
const int MOTOR_PIN = 23;

LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  Serial.begin(9600);
  IrReceiver.begin(IR_PIN);
  lcd.init();
  lcd.backlight();
  pinMode(MOTOR_PIN, OUTPUT);
  Serial.println("System Online");
}

void loop() {
  if (IrReceiver.decode()) {
    analogWrite(MOTOR_PIN, 180);
    IrReceiver.resume();
  }
}
```
