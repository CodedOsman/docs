## Building the circuit

Things Needed:

- Arduino Uno Core Board
- 4x4 Matrix Keypad
- Stepper Motor
- ULN2003 Driver
- USB Cable & Jumper Wires

## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Connect the Arduino 5V pin to the breadboard's positive (+) power rail and the Arduino GND pin to the negative (-) power rail.

**Step 2:** Place the 4x4 Matrix Keypad on the breadboard.
  - Connect the 8 row and column pins to Digital Pins 2, 3, 4, 5, 6, 7, and Analog Pins A0, A1 respectively

**Step 3:** Place the ULN2003 Motor Driver Board on the breadboard (for the Stepper Motor).
  - Connect the VCC pin to the 5V power rail on the breadboard
  - Connect the GND pin to the ground rail on the breadboard
  - Connect IN1, IN2, IN3, and IN4 to Digital Pins 8, 9, 10, and 11 respectively
  - Plug the Stepper Motor connector into the driver board

**Step 4:** Ensure all components share a common GND connection, then verify all wiring before connecting the Arduino Uno to your computer using the USB cable.

![Components on breadboard](../../../assets/coder_pro/4.0/4.2.28_Project_118_Keypad_Controlled_Stepper_Rotation_Table/image_1.png)

**Step 5:** After confirming that all connections are correct, connect the USB cable to the Arduino Uno board and the computer to power the circuit.

_Make sure to connect the Arduino USB cable to the Arduino board._

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
#include <Keypad.h>
#include <Stepper.h>
#include <TM1637Display.h>

const byte ROWS = 4;
const byte COLS = 4;
byte rowPins[ROWS] = {2, 3, 4, 5};
byte colPins[COLS] = {6, 7, 8, 9};
char keys[ROWS][COLS] = {
  {'1','2','3','A'}, {'4','5','6','B'}, 
  {'7','8','9','C'}, {'*','0','#','D'}
};
Keypad keypad = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS);

const int stepsPerRev = 2048;
Stepper myStepper(stepsPerRev, 10, 12, 11, 13);
TM1637Display display(A1, A0);

void setup() {
  Serial.begin(9600);
  display.setBrightness(0x0f);
  display.showNumberDec(0);
  Serial.println("Project 118: Initialized");
}

void loop() {
  char key = keypad.getKey();
  if (key) {
    Serial.println(key);
  }
}
```
