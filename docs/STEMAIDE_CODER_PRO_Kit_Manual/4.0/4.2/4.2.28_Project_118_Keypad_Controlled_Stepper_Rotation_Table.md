## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Inventory all modules listed in the Required Components table.

**Step 2:** Connect the 4x4 Matrix Keypad: Rows to Arduino pins D2, D3, D4, D5 and Columns to pins D6, D7, D8, D9.

**Step 3:** Connect the ULN2003 Driver input pins to Arduino pins D10, D11, D12, D13.

**Step 4:** Connect the TM1637 Display: DIO to A0 and CLK to A1.

**Step 5:** Double-check all VCC, 5V, 3.3V, and GND polarities to prevent electrical shorts.

**Step 6:** Connect USB programming cable only after verifying all signal path wiring.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
#include <Keypad.h>
#include <Stepper.h>
#include <TM1637Display.h>

const byte ROWS = 4;
const byte COLS = 4;
byte rowPins[ROWS] = {2, 3, 4, 5};
byte colPins[COLS] = {6, 7, 8, 9};
char keys[ROWS][COLS] = {
  {'1','2','3','A'}, {'4','5','6','B'}, 
  {'7','8','9','C'}, {'*','0','#','D'}
};
Keypad keypad = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS);

const int stepsPerRev = 2048;
Stepper myStepper(stepsPerRev, 10, 12, 11, 13);
TM1637Display display(A1, A0);

void setup() {
  Serial.begin(9600);
  display.setBrightness(0x0f);
  display.showNumberDec(0);
  Serial.println("Project 118: Initialized");
}

void loop() {
  char key = keypad.getKey();
  if (key) {
    Serial.println(key);
  }
}
```
