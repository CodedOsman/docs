## Building the circuit

Things Needed:

- Arduino Uno Core Board
- 4x4 Keypad
- XY Joystick
- IIC 1602 LCD
- USB Cable & Jumper Wires

## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Connect the Arduino 5V pin to the breadboard's positive (+) power rail and the Arduino GND pin to the negative (-) power rail.

**Step 2:** Place the 4x4 Keypad on the breadboard.
  - Connect the 8 row and column pins to Digital Pins 2, 3, 4, 5, 6, 7, 10, and 11 respectively

**Step 3:** Place the XY Joystick on the breadboard.
  - Connect the VCC pin to the 5V power rail on the breadboard
  - Connect the GND pin to the ground rail on the breadboard
  - Connect the VRx pin to Analog Pin A0
  - Connect the VRy pin to Analog Pin A1

**Step 4:** Place the IIC 1602 LCD on the breadboard.
  - Connect the VCC pin to the 5V power rail on the breadboard
  - Connect the GND pin to the ground rail on the breadboard
  - Connect the SDA pin to Analog Pin A4
  - Connect the SCL pin to Analog Pin A5

**Step 5:** Place the Active Buzzer on the breadboard.
  - Connect its positive (+) pin to Analog Pin A2
  - Connect its negative (-) pin to the ground rail on the breadboard

**Step 6:** Ensure all components share a common GND connection, then verify all wiring before connecting the Arduino Uno to your computer using the USB cable.

![Components on breadboard](../../../assets/coder_pro/4.0/4.2.30_Project_120_Master_Keypad__Joystick_Automation_Console/image_1.png)

**Step 7:** After confirming that all connections are correct, connect the USB cable to the Arduino Uno board and the computer to power the circuit.

_Make sure to connect the Arduino USB cable to the Arduino board._

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
#include <Keypad.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <Stepper.h>

// Pin Definitions
const int JOY_X = A0, JOY_Y = A1, JOY_SW = 10;
const int BUZZER = A2;
const int STEPS_PER_REV = 2048;
Stepper motor(STEPS_PER_REV, 11, 13, 12, A3);
LiquidCrystal_I2C lcd(0x27, 16, 2);

byte rowPins[4] = {2, 3, 4, 5};
byte colPins[4] = {6, 7, 8, 9};
char keys[4][4] = {{'1','2','3','A'},{'4','5','6','B'},{'7','8','9','C'},{'*','0','#','D'}};
Keypad keypad = Keypad(makeKeymap(keys), rowPins, colPins, 4, 4);

void setup() {
  Serial.begin(9600);
  pinMode(JOY_SW, INPUT_PULLUP);
  pinMode(BUZZER, OUTPUT);
  lcd.init();
  lcd.backlight();
  lcd.print("Console Online");
  motor.setSpeed(10);
  Serial.println("Project 120 initialized.");
}

void loop() {
  char key = keypad.getKey();
  if (key) Serial.println(key);
  delay(10);
}
```
