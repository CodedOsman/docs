## Building the circuit

- XY Joystick = 1
- Stepper Motor = 1
- IIC 1602 LCD = 1
- USB Cable & Jumper Wires = 1

## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Inventory all modules listed in the Required Components table.

**Step 2:** Connect the Joystick: VRx to A0, VRy to A1, and SW to Digital Pin 2.

**Step 3:** Wire the ULN2003 Driver: IN1 to D8, IN2 to D9, IN3 to D10, and IN4 to D11; then connect the I2C LCD SDA to A4 and SCL to A5.

**Step 4:** Connect all VCC/5V pins to the Arduino 5V rail and all GND pins to the Arduino GND rail.

**Step 5:** Double-check all VCC, 5V, 3.3V, and GND polarities to prevent electrical shorts.

**Step 6:** Connect USB programming cable only after verifying all signal path wiring.

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
#include <Stepper.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

const int stepsPerRevolution = 2048;
Stepper myStepper(stepsPerRevolution, 8, 10, 9, 11);
LiquidCrystal_I2C lcd(0x27, 16, 2);

const int joyX = A0;
const int joySW = 2;

void setup() {
  myStepper.setSpeed(10);
  lcd.init();
  lcd.backlight();
  pinMode(joySW, INPUT_PULLUP);
  lcd.setCursor(0, 0);
  lcd.print("System Ready");
}

void loop() {
  int xVal = analogRead(joyX);
  if (xVal < 400) {
    myStepper.step(10);
    lcd.setCursor(0, 1);
    lcd.print("Moving CW ");
  } else if (xVal > 600) {
    myStepper.step(-10);
    lcd.setCursor(0, 1);
    lcd.print("Moving CCW");
  } else {
    lcd.setCursor(0, 1);
    lcd.print("Stationary");
  }
}
```
