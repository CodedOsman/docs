## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Connect the Arduino 5V pin to the breadboard positive (+) power rail to supply power to the circuit using jumper wires.

- Connect the Arduino GND pin to the breadboard negative (−) power rail to establish a common ground reference using jumper wires.

- Connect the Water Sensor by wiring VCC to 5V, GND to GND, and Signal (S) to Digital Pin D7 to enable water level detection using jumper wires.

- Connect the Active Buzzer by wiring the positive (+) terminal to Digital Pin D12 and the negative (−) terminal to GND to provide an audible alarm using jumper wires.

- Connect the I²C LCD Module by wiring VCC to 5V, GND to GND, SDA to A4, and SCL to A5 to enable communication with the Arduino using jumper wires.

- Verify that all power, ground, and signal connections are secure, correctly polarized, and match the circuit diagram before powering the circuit.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// LCD Address (Change to 0x3F if required)
LiquidCrystal_I2C lcd(0x27, 16, 2);

// Pin Definitions
const int waterSensorPin = 7;     // Digital output from Water Sensor
const int buzzerPin = 12;

// Variables
bool waterDetected = false;

void setup()
{
  pinMode(waterSensorPin, INPUT);
  pinMode(buzzerPin, OUTPUT);

  digitalWrite(buzzerPin, LOW);

  Serial.begin(9600);

  lcd.init();
  lcd.backlight();

  lcd.clear();
  lcd.setCursor(0,0);
  lcd.print("Plant Monitor");
  lcd.setCursor(0,1);
  lcd.print("Initializing");

  delay(2000);
  lcd.clear();

  Serial.println("Project 64 Started...");
}

void loop()
{
  waterDetected = digitalRead(waterSensorPin);

  lcd.clear();

  if (waterDetected == HIGH)
  {
    lcd.setCursor(0,0);
    lcd.print("Water Detected");

    lcd.setCursor(0,1);
    lcd.print("Plant is Wet");

    digitalWrite(buzzerPin, LOW);

    Serial.println("Water Detected");
  }
  else
  {
    lcd.setCursor(0,0);
    lcd.print("No Water!");

    lcd.setCursor(0,1);
    lcd.print("Needs Water");

    digitalWrite(buzzerPin, HIGH);

    Serial.println("No Water Detected");

    delay(300);

    digitalWrite(buzzerPin, LOW);

    delay(300);
  }

  delay(500);
}

```
