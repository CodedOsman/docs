## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Inventory all modules listed in the Required Components table.

**Step 2:** Connect line [BME280 VCC] to [3.3V] — (Power supply for sensor module.).

**Step 3:** Connect line [BME280 GND] to [GND] — (Common ground.).

**Step 4:** Connect line [BME280 SDA] to [A4 (SDA)] — (Shared I2C Data line.).

**Step 5:** Connect line [BME280 SCL] to [A5 (SCL)] — (Shared I2C Clock line.).

**Step 6:** Connect line [IIC LCD VCC] to [5V] — (Power supply for LCD screen.).

**Step 7:** Connect line [IIC LCD GND] to [GND] — (Common ground.).

**Step 8:** Connect line [IIC LCD SDA] to [A4 (SDA)] — (Shared I2C Data line.).

**Step 9:** Connect line [IIC LCD SCL] to [A5 (SCL)] — (Shared I2C Clock line.).

**Step 10:** Double-check all VCC, 5V, 3.3V, and GND polarities to prevent electrical shorts.

**Step 11:** Connect USB programming cable only after verifying all signal path wiring.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
// Project 62: BME280 LCD Environmental Monitor
#include <Wire.h>
#include <Adafruit_BME280.h>
#include <LiquidCrystal_I2C.h>

Adafruit_BME280 bme;
LiquidCrystal_I2C lcd(0x27, 16, 2);

unsigned long lastUpdate = 0;
const long interval = 2000;

void setup() {
  Wire.begin();
  lcd.init();
  lcd.backlight();
  lcd.setCursor(0, 0);
  lcd.print("BME280 Station");
  lcd.setCursor(0, 1);
  lcd.print("Initializing...");
  delay(1500);

  if (!bme.begin(0x76)) {
    lcd.clear();
    lcd.print("BME280 Error!");
    while (1);
  }
  lcd.clear();
}

void loop() {
  if (millis() - lastUpdate >= interval) {
    lastUpdate = millis();
    float temp = bme.readTemperature();
    float hum = bme.readHumidity();
    float pres = bme.readPressure() / 100.0F;

    lcd.setCursor(0, 0);
    lcd.print("T:"); lcd.print(temp, 1); lcd.print("C H:"); lcd.print(hum, 0); lcd.print("%");
    lcd.setCursor(0, 1);
    lcd.print("P:"); lcd.print(pres, 1); lcd.print(" hPa    ");
  }
}
```
