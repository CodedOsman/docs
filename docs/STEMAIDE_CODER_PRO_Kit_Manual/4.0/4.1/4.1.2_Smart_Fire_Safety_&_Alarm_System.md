## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Connect [Arduino 5V] to [Breadboard (+) Power Rail] — (Provides a shared 5V power supply for connected components.)

**Step 2:** Connect [Arduino GND] to [Breadboard (-) Power Rail] — (Provides a common ground connection.)

**Step 3:** Connect [Flame Sensor VCC] to [Breadboard (+) Power Rail] — (Supplies 5V power to the flame sensor.)

**Step 4:** Connect [Flame Sensor GND] to [Breadboard (-) Power Rail] — (Completes the sensor ground connection.)

**Step 5:** Connect [Relay VCC] to [Breadboard (+) Power Rail] — (Supplies power to the relay module.)

**Step 6:** Connect [Relay GND] to [Breadboard (-) Power Rail] — (Completes the relay ground connection.)

**Step 7:** Connect [Flame Sensor DO] to [Arduino Pin 2] — (Digital flame detection input.)

**Step 8:** Connect [Relay IN] to [Arduino Pin 7] — (Relay control signal.)

**Step 9:** Connect [Buzzer (+)] to [Arduino Pin 8] — (Audio alarm output.)

**Step 10:** Connect [LED Anode] to [Arduino Pin 13 via 220Ω resistor] — (Visual alert indicator.)

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp
// Project 63: Smart Fire Safety & Alarm System
const int flamePin = 2;
const int relayPin = 7;
const int buzzerPin = 8;
const int ledPin = 13;

void setup() {
  pinMode(flamePin, INPUT);
  pinMode(relayPin, OUTPUT);
  pinMode(buzzerPin, OUTPUT);
  pinMode(ledPin, OUTPUT);
  digitalWrite(relayPin, LOW);
  digitalWrite(buzzerPin, LOW);
  digitalWrite(ledPin, LOW);
}

void loop() {
  if (digitalRead(flamePin) == LOW) {
    digitalWrite(relayPin, HIGH);
    digitalWrite(ledPin, HIGH);
    digitalWrite(buzzerPin, HIGH);
    delay(100);
    digitalWrite(buzzerPin, LOW);
    delay(100);
  } else {
    digitalWrite(relayPin, LOW);
    digitalWrite(ledPin, LOW);
    digitalWrite(buzzerPin, LOW);
    delay(200);
  }
}


```
