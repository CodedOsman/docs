# Project 4.3.22: Bluetooth Remote Matrix Display Scroller

| **Description** | In this Project, learners will build a Bluetooth-driven scrolling text display using an HC-05 Bluetooth module and a MAX7219 8×8 LED Dot Matrix. Characters typed on a smartphone Bluetooth terminal are received by the Arduino and displayed as scrolling text on the matrix. A buzzer provides an audio cue whenever a message is received, simulating a wireless announcement or digital signage display.|
|------------------|----------------------------------------------------------------|
| **Use case**     |Wireless scrolling displays are used in shops, bus/train stations, event venues, emergency alert boards, and warehouse pickers' floors where information needs to be updated remotely without physical access. This project introduces learners to SPI dot-matrix drivers and wireless display update patterns.|

- Active Buzzer = 1
- USB Cable & Jumper Wires

## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Place the Arduino Uno and breadboard on your workspace. Connect the 5V and GND pins to the breadboard power rails.

**Step 2:** Place the HC-05 Bluetooth module. Connect VCC to 5V, GND to GND, TXD to Arduino Pin 2 (RX), and RXD to Arduino Pin 3 (TX — use a voltage divider or level shifter for the RXD line).

**Step 3:** Place the MAX7219 Dot Matrix module. Connect VCC to 5V, GND to GND, DIN to Arduino Pin 12, CS to Arduino Pin 10, and CLK to Arduino Pin 11.

**Step 4:** Place the active buzzer. Connect the positive (+) pin to Arduino Pin 9 and the negative (–) pin to GND.

**Step 5:** Verify all VCC and GND connections and confirm the SPI wires to the MAX7219 are correct (DIN=12, CLK=11, CS=10), then connect the Arduino USB cable to the computer.

```cpp
#include <LedControl.h>
#include <SoftwareSerial.h>

// MAX7219: DIN=12, CLK=11, CS=10, 1 device
LedControl lc = LedControl(12, 11, 10, 1);
SoftwareSerial BT(2, 3); // RX, TX
const int buzzerPin = 9;

// Basic 5x3 font for characters ' ' and 'A'-'Z' (simplified)
// Row bitmask per character for scrolling (uses byte arrays)
byte charSet[27][8] = {
  {0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00}, // ' '
  {0x18,0x24,0x42,0x7E,0x42,0x42,0x42,0x00}, // A
  {0x7C,0x42,0x42,0x7C,0x42,0x42,0x7C,0x00}, // B
  {0x3C,0x42,0x40,0x40,0x40,0x42,0x3C,0x00}, // C
  {0x78,0x44,0x42,0x42,0x42,0x44,0x78,0x00}, // D
  {0x7E,0x40,0x40,0x7C,0x40,0x40,0x7E,0x00}, // E
  {0x7E,0x40,0x40,0x7C,0x40,0x40,0x40,0x00}, // F
  {0x3C,0x42,0x40,0x4E,0x42,0x42,0x3C,0x00}, // G
  {0x42,0x42,0x42,0x7E,0x42,0x42,0x42,0x00}, // H
  {0x3E,0x08,0x08,0x08,0x08,0x08,0x3E,0x00}, // I
  {0x02,0x02,0x02,0x02,0x42,0x42,0x3C,0x00}, // J
  {0x44,0x48,0x50,0x60,0x50,0x48,0x44,0x00}, // K
  {0x40,0x40,0x40,0x40,0x40,0x40,0x7E,0x00}, // L
  {0x42,0x66,0x5A,0x42,0x42,0x42,0x42,0x00}, // M
  {0x42,0x62,0x52,0x4A,0x46,0x42,0x42,0x00}, // N
  {0x3C,0x42,0x42,0x42,0x42,0x42,0x3C,0x00}, // O
  {0x7C,0x42,0x42,0x7C,0x40,0x40,0x40,0x00}, // P
  {0x3C,0x42,0x42,0x42,0x52,0x4A,0x3C,0x00}, // Q
  {0x7C,0x42,0x42,0x7C,0x50,0x48,0x44,0x00}, // R
  {0x3C,0x42,0x40,0x3C,0x02,0x42,0x3C,0x00}, // S
  {0x7F,0x08,0x08,0x08,0x08,0x08,0x08,0x00}, // T
  {0x42,0x42,0x42,0x42,0x42,0x42,0x3C,0x00}, // U
  {0x42,0x42,0x42,0x42,0x42,0x24,0x18,0x00}, // V
  {0x42,0x42,0x42,0x42,0x5A,0x66,0x42,0x00}, // W
  {0x42,0x24,0x18,0x18,0x24,0x42,0x00,0x00}, // X
  {0x42,0x42,0x24,0x18,0x08,0x08,0x08,0x00}, // Y
  {0x7E,0x04,0x08,0x10,0x20,0x40,0x7E,0x00}, // Z
};

String message = "";

void setup() {
  Serial.begin(9600);
  BT.begin(9600);
  pinMode(buzzerPin, OUTPUT);
  lc.shutdown(0, false);
  lc.setIntensity(0, 8);
  lc.clearDisplay(0);
  showChar(' ');
  Serial.println("Project 142: Bluetooth Matrix Scroller Online");
  Serial.println("Send text from Bluetooth terminal...");
}

void showChar(char c) {
  int idx = 0;
  if (c >= 'A' && c <= 'Z') idx = c - 'A' + 1;
  else if (c >= 'a' && c <= 'z') idx = c - 'a' + 1;
  for (int r = 0; r < 8; r++) lc.setRow(0, r, charSet[idx][r]);
}

void loop() {
  if (BT.available()) {
    char ch = BT.read();
    if (ch == '\n' || ch == '\r') return;
    tone(buzzerPin, 1000, 80);
    showChar(ch);
    Serial.print("Displaying: "); Serial.println(ch);
  }
}
```

## CONCLUSION

The Bluetooth Remote Matrix Display Scroller project demonstrates how an HC-05 "
Bluetooth module and a MAX7219 LED matrix can be combined to create a wireless "
digital signage panel. Characters sent from a smartphone are instantly rendered "
on the matrix display with an audio beep confirmation.

The main system flow is:

Smartphone → HC-05 → Arduino → MAX7219 Matrix → Displayed Character

Through this project, learners gain experience with SPI-driven LED matrix displays, "
font rendering on limited-resolution hardware, and building wireless display "
update pipelines — skills directly applicable to IoT dashboards and signage systems.
