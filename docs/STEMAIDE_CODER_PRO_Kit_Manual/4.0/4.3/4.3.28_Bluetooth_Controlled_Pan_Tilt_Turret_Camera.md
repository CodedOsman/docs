# Project 4.3.28: Project 148 Bluetooth Controlled Pan-Tilt Turret Camera

| **Description** In Project 148, learners will build a Bluetooth-controlled pan-tilt turret platform using an HC-05 Bluetooth module, two SG90 servo motors, an RGB LED module, and a buzzer. Single-character commands from a smartphone terminal control horizontal pan (left/right) and vertical tilt (up/down) of the platform in 15° increments. The RGB LED indicates the current operating direction and the buzzer provides an audio cue on each command, simulating a wireless remote-control security camera mount.|
|------------------|----------------------------------------------------------------|
| **Use case**     |Pan-tilt turret platforms are used in CCTV camera mounts, drone gimbal systems, industrial inspection arms, and FPV robot turrets where a two-axis servo system provides remote directional control. This project introduces learners to dual-servo coordination and multi-axis Bluetooth control system design.|

## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Place the Arduino Uno and breadboard on your workspace. Connect the 5V and GND pins to the breadboard power rails.

**Step 2:** Place the HC-05 Bluetooth module. Connect HC-05 VCC to 5V, GND to GND, TXD to Arduino Pin 2 (RX), and RXD to Arduino Pin 3 (TX — use a voltage divider or level shifter).

**Step 3:** Connect Servo 1 (Pan): red (VCC) to 5V, brown/black (GND) to GND, orange/yellow (signal) to Arduino Pin 9.

**Step 4:** Connect Servo 2 (Tilt): red (VCC) to 5V, brown/black (GND) to GND, orange/yellow (signal) to Arduino Pin 10.

**Step 5:** Connect the RGB LED module: R to Arduino Pin 5, G to Pin 6, B to Pin 7 (through 220 Ω resistors each), and common cathode/GND to GND.

**Step 6:** Place the active buzzer. Connect the positive (+) pin to Arduino Pin 12 and the negative (–) pin to GND.

**Step 7:** Verify all VCC and GND connections, then connect the Arduino USB cable to the computer.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../../STEMAIDE_CODER_Kit_Manual/Getting_Started/Arduino_IDE_Setup.md).

**Step 2:** Copy and paste the program below into your IDE. Study each section to understand how the Bluetooth Pan-Tilt Turret works.

```cpp
#include <Servo.h>
#include <SoftwareSerial.h>

SoftwareSerial BT(2, 3); // RX, TX

Servo panServo;
Servo tiltServo;

const int redPin   = 5;
const int greenPin = 6;
const int bluePin  = 7;
const int buzzerPin = 12;

int panAngle  = 90; // Start centred
int tiltAngle = 90;
const int step = 15; // Degrees per command

void setRGB(int r, int g, int b) {
  analogWrite(redPin, r); analogWrite(greenPin, g); analogWrite(bluePin, b);
}

void setup() {
  Serial.begin(9600);
  BT.begin(9600);
  panServo.attach(9);
  tiltServo.attach(10);
  panServo.write(panAngle);
  tiltServo.write(tiltAngle);
  pinMode(redPin,    OUTPUT);
  pinMode(greenPin,  OUTPUT);
  pinMode(bluePin,   OUTPUT);
  pinMode(buzzerPin, OUTPUT);
  setRGB(0, 255, 0); // Green = Ready
  Serial.println("Project 148: Bluetooth Pan-Tilt Turret Online");
  BT.println("Commands: L=Left R=Right U=Up D=Down C=Centre");
}

void loop() {
  if (BT.available()) {
    char cmd = BT.read();
    tone(buzzerPin, 1000, 80);

    switch (cmd) {
      case 'L': case 'l':
        panAngle = constrain(panAngle - step, 0, 180);
        panServo.write(panAngle);
        setRGB(255, 0, 0); // Red = Left
        Serial.print("Pan LEFT -> "); Serial.println(panAngle);
        break;
      case 'R': case 'r':
        panAngle = constrain(panAngle + step, 0, 180);
        panServo.write(panAngle);
        setRGB(0, 0, 255); // Blue = Right
        Serial.print("Pan RIGHT -> "); Serial.println(panAngle);
        break;
      case 'U': case 'u':
        tiltAngle = constrain(tiltAngle + step, 0, 180);
        tiltServo.write(tiltAngle);
        setRGB(255, 255, 0); // Yellow = Up
        Serial.print("Tilt UP -> "); Serial.println(tiltAngle);
        break;
      case 'D': case 'd':
        tiltAngle = constrain(tiltAngle - step, 0, 180);
        tiltServo.write(tiltAngle);
        setRGB(0, 255, 255); // Cyan = Down
        Serial.print("Tilt DOWN -> "); Serial.println(tiltAngle);
        break;
      case 'C': case 'c':
        panAngle = 90; tiltAngle = 90;
        panServo.write(90); tiltServo.write(90);
        setRGB(0, 255, 0); // Green = Centre
        Serial.println("Both servos centred");
        break;
      default:
        Serial.print("Unknown cmd: "); Serial.println(cmd);
        break;
    }
    BT.print("Pan:"); BT.print(panAngle); BT.print(" Tilt:"); BT.println(tiltAngle);
  }
}
```

## CONCLUSION

The Bluetooth Controlled Pan-Tilt Turret Camera project demonstrates how a "
two-servo pan-tilt mechanism can be wirelessly controlled from a smartphone "
terminal. Each Bluetooth command moves the platform 15° in the specified "
direction, while the RGB LED provides a colour-coded directional indicator "
and the buzzer confirms each command.

The main system flow is:

Smartphone → HC-05 → Arduino → Pan/Tilt Servos + RGB LED + Buzzer

Through this project, learners master dual-servo coordination, multi-axis "
directional control, and Bluetooth command parsing — foundational skills "
for robotics, remote inspection systems, and autonomous camera platforms.
