# Project 4.3.17: Project 137 Real-Time Clock Greenhouse Light Automation

| **Description** In Project 137, learners will build an automated greenhouse lighting system that integrates a DS3231 RTC module, a Photoresistor (LDR), and a Relay Module. The RTC defines the valid grow-light schedule (06:00–20:00), while the LDR continuously measures ambient light levels. The relay switches the grow light ON only when it is both within the scheduled hours and the ambient light level falls below a calibrated darkness threshold.|
|------------------|----------------------------------------------------------------|
| **Use case**     |Automated grow-light systems are deployed in commercial greenhouses, vertical farms, and hydroponics labs to supplement natural sunlight. By combining time-based scheduling with real-time light sensing, the system prevents unnecessary light exposure and reduces electricity costs.|

## Mounting the component on the breadboard and wiring the circuit

**Step 1:** Place the Arduino Uno and breadboard on your workspace. Connect the 5V and GND pins to the breadboard power rails.

**Step 2:** Place the DS3231 RTC module on the breadboard. Connect DS3231 VCC to 5V, GND to GND, SDA to Arduino A4, and SCL to Arduino A5.

**Step 3:** Build the LDR voltage-divider circuit: connect one leg of the LDR to 5V and the other leg to Analog Pin A0. Connect a 10 kΩ resistor from A0 to GND (pull-down). The voltage at A0 decreases as the environment gets darker.

**Step 4:** Place the relay module. Connect relay VCC to 5V, GND to GND, and IN to Arduino Digital Pin 8.

**Step 5:** Place the active buzzer. Connect the positive (+) pin to Arduino Digital Pin 9 and the negative (–) pin to GND.

**Step 6:** Verify all VCC and GND polarities, then connect the Arduino USB cable to the computer.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../../STEMAIDE_CODER_Kit_Manual/Getting_Started/Arduino_IDE_Setup.md).

**Step 2:** Copy and paste the program below into your IDE. Study each section to understand how the Greenhouse Light Automation works.

```cpp
#include <Wire.h>
#include <RTClib.h>

const int relayPin      = 8;
const int buzzerPin     = 9;
const int ldrPin        = A0;
const int darkThreshold = 400; // Calibrate: lower value = darker

RTC_DS3231 rtc;

void setup() {
  Serial.begin(9600);
  pinMode(relayPin,  OUTPUT);
  pinMode(buzzerPin, OUTPUT);
  digitalWrite(relayPin, HIGH); // Relay OFF (Active-LOW module)

  Wire.begin();
  if (!rtc.begin()) {
    Serial.println("RTC not found!");
    while (1);
  }
  if (rtc.lostPower()) rtc.adjust(DateTime(F(__DATE__), F(__TIME__)));
  Serial.println("Project 137: Greenhouse Light Automation Online");
}

void loop() {
  DateTime now      = rtc.now();
  int ldrValue      = analogRead(ldrPin);
  bool isScheduled  = (now.hour() >= 6 && now.hour() < 20);
  bool isDark        = (ldrValue < darkThreshold);

  Serial.print("Time: "); Serial.print(now.hour()); Serial.print(":"); Serial.print(now.minute());
  Serial.print(" | LDR: "); Serial.print(ldrValue);
  Serial.print(" | Scheduled: "); Serial.print(isScheduled ? "YES" : "NO");
  Serial.print(" | Dark: "); Serial.println(isDark ? "YES" : "NO");

  if (isScheduled && isDark) {
    digitalWrite(relayPin, LOW);  // Grow Light ON
  } else {
    digitalWrite(relayPin, HIGH); // Grow Light OFF
  }

  delay(2000);
}
```

## CONCLUSION

The Real-Time Clock Greenhouse Light Automation project demonstrates dual-condition "
automated control, combining a time schedule from the DS3231 RTC with a live ambient "
light reading from the LDR. The relay-switched grow light activates only when "
both the scheduled grow window is active AND the environment is too dark.

The main system flow is:

RTC + LDR → Arduino → Relay → Grow Light

Through this project, learners apply real-time scheduling, analogue sensing, and "
threshold-based decision logic — core skills for professional greenhouse automation systems.
