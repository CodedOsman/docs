# References & External Learning Resources (Coder Pro)

This manual leverages industry-standard guidelines from electrical engineering, computer science, and automation systems. Below is a curated list of official documentation, textbooks, and interactive platforms for extending your knowledge beyond the projects.

---

## 1. Official Documentation & Protocol References

*   **Official Arduino Reference**: The absolute authority on C++ programming syntax, variables, structure, and built-in functions for the Arduino platform.
    *   *Link*: [https://www.arduino.cc/reference/en/](https://www.arduino.cc/reference/en/)
*   **I2C (Wire Library) Documentation**: The official reference on how to communicate with devices using the Inter-Integrated Circuit bus (such as the I2C LCD and BME280).
    *   *Link*: [https://www.arduino.cc/reference/en/language/functions/communication/wire/](https://www.arduino.cc/reference/en/language/functions/communication/wire/)
*   **SPI Library Reference**: Official guide on standard Serial Peripheral Interface communication (used by the MFRC522 RFID reader).
    *   *Link*: [https://www.arduino.cc/reference/en/language/functions/communication/spi/](https://www.arduino.cc/reference/en/language/functions/communication/spi/)
*   **MFRC522 RFID Library**: The primary GitHub repository for the library used to control the RFID reader, including sample codes and pinouts.
    *   *Link*: [https://github.com/miguelbalboa/rfid](https://github.com/miguelbalboa/rfid)
*   **Keypad Library**: Official documentation and usage guidelines for multiplexed matrix keypads.
    *   *Link*: [https://playground.arduino.cc/Code/Keypad/](https://playground.arduino.cc/Code/Keypad/)
*   **RTClib Library**: The Adafruit repository for interfacing with DS1307 and DS3231 Real-Time Clock modules.
    *   *Link*: [https://github.com/adafruit/RTClib](https://github.com/adafruit/RTClib)
*   **Adafruit BME280 Library**: The source code repository and usage examples for reading temperature, humidity, and pressure.
    *   *Link*: [https://github.com/adafruit/Adafruit_BME280_Library](https://github.com/adafruit/Adafruit_BME280_Library)
*   **OneWire & DallasTemperature**: Libraries for interfacing with the DS18B20 1-Wire temperature sensor.
    *   *OneWire Link*: [https://www.pjrc.com/teensy/td_libs_OneWire.html](https://www.pjrc.com/teensy/td_libs_OneWire.html)
    *   *DallasTemperature Link*: [https://github.com/milesburton/Arduino-Temperature-Control-Library](https://github.com/milesburton/Arduino-Temperature-Control-Library)

## 2. Advanced Texts & Textbooks

*   **Monk, S. (2019). *Programming Arduino: Getting Started with Sketches* (2nd ed.). McGraw-Hill Education.**
    *   A great bridge from basic C++ scripting to advanced structural patterns, custom libraries, and memory optimization.
*   **Scherz, P., & Monk, S. (2016). *Practical Electronics for Inventors* (4th ed.). McGraw-Hill Education.**
    *   A massive engineering manual covering components, motor drivers (H-Bridges), capacitors, relays, and noise decoupling.
*   **Karvinen, T., Karvinen, K., & Valtokari, V. (2014). *Make: Sensors*. Maker Media, Inc.**
    *   A hands-on reference book explaining the physics and calibration techniques behind acoustic, optics, proximity, and environmental sensors.
*   **Margolis, M. (2020). *Arduino Cookbook* (3rd ed.). O'Reilly Media.**
    *   A catalog of advanced solutions for interfacing with SPI, I2C, keypads, shift registers, and stepper motors.

## 3. Interactive Web Tools & Simulators

*   **Wokwi Simulator**: A web-based, hardware-accurate simulator that supports the Arduino Uno, ESP32, and Raspberry Pi Pico. You can mock up keypads, I2C LCDs, RTC modules, and write complex code directly in the browser to test before building.
    *   *Link*: [https://wokwi.com/](https://wokwi.com/)
*   **Tinkercad Circuits**: A 3D circuit prototyping tool by Autodesk that allows users to wire up basic components, test logic, and measure voltages.
    *   *Link*: [https://www.tinkercad.com/](https://www.tinkercad.com/)
*   **Fritzing**: An open-source program that helps makers document their physical prototypes by turning breadboard sketches into clean schematic diagrams.
    *   *Link*: [https://fritzing.org/](https://fritzing.org/)
