# Project 2.14: Touch-Free Hand Sanitizer Simulator

| **Description** | This project demonstrates a contactless automation system that uses proximity sensing to simulate hand sanitizer dispensing. It introduces the principles of sensor-triggered control and motion-based automation commonly used in public and healthcare environments. |
|------------------|----------------------------------------------------------------|
| **Use case**     | This project is connected to real-world uses such as: hospitals, airports, schools, shopping centers, and public hygiene stations. It demonstrates how proximity sensors and servo-controlled mechanisms can support touch-free automation. |

## Mounting the component on the breadboard and wiring the circuit

**Step 1:**	Place the Ultrasonic Sensor and the Servo Motor on the breadboard or in suitable positions for wiring.

- Connect the Ultrasonic Sensor by connecting VCC to 5V, GND to GND, Trig to Digital Pin 9, and Echo to Digital Pin 10 on the arduino board using jumper wires.

- Connect the Servo Motor by connecting VCC to 5V, GND to GND, and the Signal wire to Digital Pin 6 on the arduino board using jumper wires.

- Since both the Ultrasonic Sensor and Servo Motor require 5V and GND, first connect the Arduino 5V pin to the breadboard's positive (+) power rail and the Arduino GND pin to the negative (-) power rail. 

- Then connect the VCC and GND pins of both components to the corresponding breadboard power rails. Ensure that all GND connections share the same ground line to maintain stable and reliable circuit operation.

- Check the polarity of the servo motor and ultrasonic sensor, and verify that all wiring connections are correct before connecting the Arduino Uno to your computer via the USB cable.

## PROGRAMMING

**Step 1:** Open your Arduino IDE. See how to set up here: [Getting Started](../../Getting Started/Arduino_IDE_Setup.md).

**Step 2:** Write the complete program implementing the system logic with appropriate pin definitions, setup configuration, and the main control loop.

```cpp

#include <Servo.h>
Servo dispenser;
void setup() {
  dispenser.attach(6);
}
void loop() {
  // If hand detected
  dispenser.write(90);
  delay(1000);
  dispenser.write(0);
}
```

**Step 3:** Save your code. _See the [Getting Started](../../Getting Started/Arduino_IDE_Setup.md) section_
