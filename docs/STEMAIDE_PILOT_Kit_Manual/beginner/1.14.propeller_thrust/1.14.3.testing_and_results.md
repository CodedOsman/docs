## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| Test rig built | Motor securely mounted; spring scale connected; rig does not move during testing |
| All 3 propellers tested | Thrust recorded at three speed settings for each propeller |
| Current data recorded | Ammeter or current sensor used; efficiency calculated for each test point |
| Graph created | Thrust vs. motor speed plotted for all 3 propellers on one graph |
| Best propeller identified | Highest-efficiency propeller named with reference to diameter and pitch data |

## Upgrade & Extension Ideas

* Variable Speed Control: add a potentiometer (variable resistor) to set precise speed levels; measure RPM with a phone tachometer app
* Voltage Test: run the same propeller at 3V, 4.5V, and 6V; graph voltage vs. thrust
* Counter-Rotating Twin: mount two motors facing opposite directions with identical propellers; measure combined thrust vs. single motor
* Ducted Fan: wrap a cardboard duct around the propeller; measure the thrust increase from the duct effect
