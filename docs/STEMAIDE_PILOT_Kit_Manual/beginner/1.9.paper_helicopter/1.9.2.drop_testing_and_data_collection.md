# 1.9.2 Paper Helicopter Drop Testing And Data Collection

## Step-by-Step Assembly (Continued)

**Lesson 2 – Drop Testing & Data Collection**

### Step 4: Drop Testing Protocol
* Drop from a consistent height of 2 m (mark on the wall with tape)
* One student drops; one student starts the stopwatch at release
* Record time from release to landing
* Count visible rotations during the drop
* Conduct 3 drops per design; record all three times; calculate average
* Record stability observations: 'stable' (smooth rotation), 'unstable' (wobbles or drifts)

### Step 5: Analysis & Graphing
* Plot a bar graph: rotor design (x-axis) vs average drop time (y-axis)
* Identify which design had the slowest descent and which had the fastest
* Write 3 sentences explaining the results with reference to drag and rotor area
* Discuss as a class: how does this connect to helicopter autorotation?
