## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| 4 airfoils built | Clean, correct foam shapes; edges sanded smooth |
| Test rig assembled | Airfoil mounted on pivot; spring scale attached; fan at fixed distance |
| Full data collected | All four airfoils tested at 0°, 5°, 10°, 15°; all readings recorded |
| Graphs created | Lift vs. angle of attack plotted for all four airfoils on one graph |
| Stall angle identified | Critical angle noted for each airfoil where lift peaks and then drops |
| Conclusion written | Best airfoil identified and explained using Bernoulli's Principle |

## Upgrade & Extension Ideas

* Wind Tunnel Enclosure: build a cardboard enclosure around the test area to produce a more uniform airstream
* Flap Effect: score and bend the trailing 20% of the cambered airfoil down as a flap; measure lift change
* Aspect Ratio: cut two wings of equal area — one long and narrow, one short and wide; compare lift at the same angle
* Electronic Measurement: replace the spring scale with a force sensor connected to an ESP32; log data automatically
