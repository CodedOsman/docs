# 3.9.3 Vhf Radio Communication Testing And Results

## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| Phonetic alphabet learned | Student can recite all 26 ICAO phonetic words without hesitation |
| Callsign formatted | Student creates and uses a correct ICAO callsign format throughout all scenarios |
| 4 scenarios completed | Taxi, departure, en-route, and approach scenarios completed in correct ICAO phraseology |
| MAYDAY procedure performed | Student correctly initiates a MAYDAY call with all required elements |
| Assessment passed | Score of 80%+ on the 10-question RT assessment |
| Role-reversal completed | Student performs both pilot and ATC roles for at least one complete scenario |


## Troubleshooting
For common errors and troubleshooting, please refer to [Troubleshooting](../../Appendices/Troubleshooting.md#3-9-vhf-radio-communication).

## Upgrade & Extension Ideas

* Live ATC Monitoring: listen to real Accra approach control on liveatc.net; identify each transmission's phraseology elements
* Full Flight Simulation: combine with the RC simulator (Project 4) — one student flies while another provides ATC instructions via radio
* ATIS Recording: write and record a simulated ATIS broadcast for Kotoka Airport using that day's weather station data from Project 36
* Emergency Coordination: add a third role (Emergency Coordinator); practice a full airport emergency response communication chain
