# 3.1.3 Fpv Quadcopter Testing And Results

## Engineering Principles
Learn more about the theory and principles in [Engineering Principles](../../Appendices/Engineering_Principles.md#3-1-fpv-quadcopter).

## Test Verification Table

| **Test** | **Method** | **Success Criteria** | **Pass?** |
| --- | --- | --- | --- |
| **Video Feed** | Power on VTX and goggles; scan for channel | Clear, stable image with no black frames |  |
| **Camera Angle** | Check image in goggles while on ground | Horizon visible; nose of drone at bottom third of frame |  |
| **Range Test** | Walk 50 m away with goggles on | Clear image with no break-up |  |
| **Hover – FPV Only** | Pilot dons goggles; spotter confirms area clear; hover 30 s | Stable hover using FPV view only; no visual contact |  |
| **FPV Forward Flight** | Fly a slow straight line 20 m using FPV only | Maintains heading; no unintended altitude change |  |
| **FPV Turn** | Fly a gentle 90° turn using FPV only | Completes turn without significant altitude loss |  |
| **Gate Pass** | Fly through a 1 m × 1 m gate frame | Passes cleanly without touching the gate |  |


## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| Camera mounted | Secure; correct angle; propellers not in frame |
| VTX connected | Wired to correct voltage; channel set; antenna mounted vertically |
| Goggles paired | Clear image on correct channel; no break-up at 20 m |
| Spotter briefed | Spotter understands their role; communication signals agreed |
| Hover – FPV only | Stable hover for 30 s using FPV view; no direct visual contact with drone |
| Forward flight | 20 m straight flight and return, FPV only |
| Gate pass | Passes cleanly through 1 m × 1 m gate at least once |

## Upgrade & Extension Ideas

* HD FPV System – Replace analogue VTX with a DJI O3 or HDZero digital system; compare image quality and latency
* DVR Recording – Enable the goggle's built-in DVR; review your flight footage; identify technique improvements
* OSD (On-Screen Display) – Add battery voltage, flight time, and GPS coordinates overlaid on the FPV image
* Long-Range Antenna – Upgrade to a helical or patch antenna; test maximum video range in an open field
* FPV Race League – Set up a 6-gate course; run a timed club competition; award points across 3 race days
