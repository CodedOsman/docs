# 3.13.2 Flight Data Recorder Ground Test And Aircraft Installation

## Step-by-Step Assembly (Continued)

**Lesson 2 – Ground Test & Aircraft Installation**

|  |  |
| --- | --- |
| **STEP 3** | **Ground Functional Test** |
|  | * Power on FDR; wait 10 seconds for sensor warm-up * Tilt the unit through the motions in the data table (Section 6) * Remove SD card; open CSV on computer; confirm all columns populated with correct values * Verify: altitude near 0 m on ground; pitch near 0° when flat; AccZ near 1.0 g (gravity) |

|  |  |
| --- | --- |
| **STEP 4** | **Install on Aircraft** |
|  | * Mount the ESP32 + sensors in the Project 11 fuselage bay (remove temporarily for installation) * Re-check aircraft CG with FDR installed — it adds approximately 20 g; adjust ballast if needed * Ensure the BMP280 has access to outside air via a small fuselage vent * Route the USB programming port to an accessible location for easy SD card removal after landing |

**Lessons 3–4 – Flight, Download & Analysis**

|  |  |
| --- | --- |
| **STEP 5** | **Record a Flight** |
|  | * Power on FDR at least 60 seconds before takeoff * Fly a complete circuit: takeoff → climb → level cruise → descend → landing * Include at least one deliberate hard landing (teacher supervised) to create a detectable G-force event * Power off immediately after landing; remove SD card; copy CSV to computer |

|  |  |
| --- | --- |
| **STEP 6** | **Data Analysis & Graph** |
|  | * Open CSV in spreadsheet; inspect the first 10 rows for any anomalies * Create Chart 1: Time (x) vs. Altitude (m) — label takeoff, cruise, descent, landing * Create Chart 2: Time (x) vs. Pitch (°) — identify nose-up on takeoff; level cruise; nose-down descent * Create Chart 3: Time (x) vs. AccZ (g) — identify the hard landing spike (AccZ > 2g) * Write a 1-page accident investigation report: describe what the data shows happened during the flight |
