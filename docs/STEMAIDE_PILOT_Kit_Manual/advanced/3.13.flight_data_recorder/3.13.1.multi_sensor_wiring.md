# 3.13.1 Flight Data Recorder Multi Sensor Wiring

## Overview

Every commercial aircraft carries a Flight Data Recorder — the 'black box' — that continuously logs hundreds of flight parameters to crash-resistant storage. When an accident occurs, investigators download this data and reconstruct every moment of the flight. This project builds a functional miniature FDR using an ESP32, BMP280, MPU6050, and MicroSD card, installs it on the Project 11 RC aircraft, and records a real flight to CSV. After landing, students download, graph, and analyse the data — exactly as accident investigators do with a real FDR.

## Step-by-Step Assembly

**Lesson 1 – Multi-Sensor Wiring**

|  |  |
| --- | --- |
| **STEP 1** | **Wire All Three Modules** |
|  | * BMP280: VCC → 3.3V; GND → GND; SDA → GPIO 21; SCL → GPIO 22 (address 0x76) * MPU6050: VCC → 3.3V; GND → GND; SDA → GPIO 21; SCL → GPIO 22 (address 0x68) * MicroSD: VCC → 3.3V; GND → GND; MOSI → GPIO 23; MISO → GPIO 19; SCK → GPIO 18; CS → GPIO 5 * Run I2C scanner: confirm both BMP280 (0x76) and MPU6050 (0x68) detected simultaneously * Run SD test sketch: confirm card initialised and test file created |

|  |  |
| --- | --- |
| **STEP 2** | **Upload the FDR Code** |
|  | * Open the flight\_data\_recorder.ino sketch from Kit 9 USB drive * Review the logged columns: Timestamp(ms), Altitude(m), Pitch(°), Roll(°), AccZ(g), Temp(°C) * The complementary filter from Project 48 is already included — identify it in the code * Upload; open Serial Monitor: confirm data printing at 10 Hz * Insert MicroSD card; confirm 'FDR001.CSV created' message in Serial Monitor |
