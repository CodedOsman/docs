## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| All sensors wired | BMP280, MPU6050, and MicroSD module all functional; I2C scan confirms both sensors |
| CSV logging active | CSV file created on SD card with correct column headers and data values |
| Flight data recorded | FDR installed on Project 11 aircraft; CSV file generated during a real flight |
| Graph produced | Altitude, pitch, and G-force graphed vs. time; all flight phases identifiable |
| Crash event identified | A simulated hard landing event visible as G-force spike in the data |
| Real FDR comparison | Student explains 3 similarities and 1 difference between this project and a real SSFDR |

## Upgrade & Extension Ideas

* GPS Timestamp: add the NEO-6M GPS module from Project 9; replace millis() with UTC time for proper time-stamping
* Multiple Flights: modify code to create FLIGHT001.CSV, FLIGHT002.CSV etc. on each power cycle; compare two flights side-by-side
* Crash Simulation: intentionally tip the aircraft over on landing; identify the event signature in the accelerometer data
* Web Dashboard: use the ESP32 Wi-Fi to serve the CSV data as a live web page viewable on a phone
