# 3.8.2 Moments Stability  Testing And Results

## Engineering Principles
Learn more about the theory and principles in [Engineering Principles](../../Appendices/Engineering_Principles.md#3-8-moments-stability).

## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| Three-axis diagram complete | All three axes labelled on a side-view and front-view aircraft drawing |
| Moment calculations correct | At least 3 scenarios completed with correct moment arm × force values |
| Balance beam verification | Pitching moment calculation verified using Project 8 balance beam |
| Control surface demo | Project 27 demonstrator used to show each axis of rotation live |
| Three-view drawing | Correct three-view drawing produced showing all control surfaces on each axis |
| Stability analysis | Student explains which CG position produces stable, neutral, and unstable pitch |


## Troubleshooting
For common errors and troubleshooting, please refer to [Troubleshooting](../../Appendices/Troubleshooting.md#3-8-moments-stability).

## Upgrade & Extension Ideas

* Rolling Moment Calculation: calculate the rolling moment produced by differential aileron deflection on the Project 11 aircraft
* Stability Margin: measure the CG position and aerodynamic centre position on the Project 11 aircraft; calculate the static margin as a percentage of mean aerodynamic chord
* Dutch Roll Demonstration: in the RC simulator, set the CG to a very aft position; observe the Dutch roll oscillation; explain it using yaw and roll coupling
