## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| Release mechanism built | Servo arm rotates fully; hook releases cleanly; resets without jamming |
| Payload prepared | 50–100 g; compact shape; landing indicator (coloured tape or chalk) |
| CG correct with payload | Aircraft balanced at 30–33% chord with payload installed |
| Ground release test | Payload releases cleanly 5/5 times on transmitter switch command |
| Powered drop attempt | Payload released during flight; lands within 5 m of target |
| Drop log completed | 5 drop attempts recorded with approach data and distance to target |

## Upgrade & Extension Ideas

* Multiple Payloads – Add two hooks and two servos; practice releasing different payloads at different waypoints
* Parachute Delivery – Attach a small parachute to the payload; observe how it changes the ballistic path
* GPS-Triggered Release – Use a flight controller with waypoint capability; trigger servo release automatically at a GPS coordinate
* Camera-Guided Drop – Fit an FPV camera; release payload while viewing the target from the FPV feed
* Heavy Lift Challenge – Strengthen the airframe; increase payload to 200 g; test the limits of the Project 11 design
