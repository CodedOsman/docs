# 4.3.2 Servo Controlled Testing And Results

## Engineering Principles
Learn more about the theory and principles in [Engineering Principles](../../Appendices/Engineering_Principles.md#4-3-servo-controlled).

## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| Aileron model built | Wing and aileron constructed; hinge moves freely without binding |
| Servo installed | Servo mounted in wing; pushrod connects servo arm to control horn |
| Aileron deflects correctly | Right input produces right aileron down, left aileron up |
| Elevator model built | Horizontal stabilizer with elevator; correct direction verified |
| Rudder model built | Vertical fin with rudder; correct direction verified |
| All 3 surfaces demonstrated | Each surface demonstrated to teacher with correct direction explanation |


## Troubleshooting
For common errors and troubleshooting, please refer to [Troubleshooting](../../Appendices/Troubleshooting.md#4-3-servo-controlled).

## Upgrade & Extension Ideas

* Radio Control: connect the demonstrators to the Project 11 RC transmitter and receiver; fly the surfaces from across the room
* Multiple Servos: add a second aileron servo for differential aileron control; observe the difference from a single-servo setup
* Deflection Measurement: use a protractor to measure deflection angle at different servo arm positions; calculate the relationship between arm length and throw
* Flaps: add a hinged flap section to the trailing inner wing; demonstrate the lift increase by holding the panel in an airstream
