## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| Baseline measured | Aircraft weight, wing area, and baseline wing loading calculated and recorded |
| All 5 weight steps flown | Flights conducted at 0, 10, 20, 30, and 40 g additional weight |
| Data recorded | Estimated stall speed and handling score recorded for each step |
| Graph created | Wing loading vs. stall speed plotted; handling score overlaid |
| Safe limit identified | Maximum safe wing loading determined from the data; reasoning explained |
| Analysis written | Student explains the trade-off between wing loading, speed, and handling |

## Upgrade & Extension Ideas

* Glide Ratio: measure glide distance at each weight increment with motor off; graph wing loading vs. glide ratio
* Climb Rate: time the climb to 20 m altitude at each weight; graph wing loading vs. climb rate
* Wind Effect: fly the same weight configuration in 5 km/h and 10 km/h wind; compare handling scores
* Real Aircraft Comparison: calculate wing loading for a Boeing 737 and your RC plane; produce a comparison chart
