## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| Simulator completed | 3 consecutive figure-8 patterns in simulator before real flight |
| Course set up | Pylons placed; crossover marked; wind indicator in position |
| Takeoff | Clean takeoff; climbs to circuit altitude without swerve |
| Figure-8 | 3 consecutive complete patterns; both loops symmetrical |
| Landing | Within 10 m of centre mark; aligned with centre line |
| Score | 20 or more out of 30 on the scoring table |

## Upgrade & Extension Ideas

* Timed Challenge – Score both accuracy AND time; fastest correct pattern wins
* Vertical Figure-8 – For advanced pilots: fly the pattern in the vertical plane (inside loops)
* Obstacle Course – Add ribbon gates at each pylon that pilots must fly through precisely
* FPV Pattern – Fly the figure-8 in first-person view if FPV equipment is available
* Video Analysis – Record flights from the ground; review footage to identify turn entry and exit points precisely
