## Test Verification Table

| **Test** | **Method** | **Expected Result** | **Pass?** |
| --- | --- | --- | --- |
| **OLED Display** | Power on ESP32 | Shows altitude, pitch, roll values |  |
| **Altitude Reading** | Hold hand 10 cm above sensor | Reading drops to ~10 cm |  |
| **Altitude Alert** | Hold hand 5 cm above sensor | Red LED + buzzer activate |  |
| **Pitch Reading** | Tilt board 30° | Pitch value updates on display |  |
| **Attitude Alert** | Tilt board 30° | Yellow LED + buzzer activate |  |
| **Normal State** | All sensors in normal range | Green LED steady, buzzer off |  |
| **Code Upload** | USB connected; IDE upload | No errors; board resets and runs |  |


## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| OLED displays live data | Altitude, pitch, and roll update in real time |
| Altitude alert triggers | Red LED and buzzer activate at < 30 cm |
| Attitude alert triggers | Yellow LED and buzzer activate at > 25° tilt |
| Normal state confirmed | Green LED steady when all readings in range |
| Wiring diagram completed | Labelled diagram with all GPIO numbers and colour coding |
| Avionics explained | Student explains sensor → ESP32 → display data flow |

## Upgrade & Extension Ideas

* Temperature Display – Add a DHT11 sensor; display temperature and humidity alongside altitude and attitude
* Heading Indicator – Add an HMC5883L compass module (also I2C); display compass heading on the OLED
* Data Logger – Add a MicroSD card module; log all sensor readings to a CSV file for post-flight analysis
* Bluetooth Telemetry – Send live data to a smartphone via the ESP32's built-in Bluetooth module
* Physical Cockpit Panel – Mount all components in a cardboard or 3D-printed instrument panel fascia
