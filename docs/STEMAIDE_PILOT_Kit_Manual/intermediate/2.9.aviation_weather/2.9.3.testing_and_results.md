## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| Station assembled | All sensors wired and reading; OLED displays live values |
| One week of data | Minimum 3 readings per day for 5 days; all rows in data table filled |
| Graphs created | Temperature, pressure, and wind speed graphed vs. time |
| Density altitude calculated | Daily density altitude calculated and graphed |
| Aviation impact explained | Student links each weather variable to a specific aircraft performance effect |
| METAR decoded | At least one real GCAA METAR from Kotoka Airport decoded and explained |

## Upgrade & Extension Ideas

* Wind Direction: add a compass module (QMC5883L); display 8-point compass direction alongside wind speed
* Rain Gauge: add a tipping-bucket rain gauge; log rainfall in mm per day
* Solar Irradiance: add a BH1750 light intensity sensor; log irradiance in W/m² (connects directly to Project 35 solar aircraft power budget)
* ATIS Broadcast: write a simple code that generates an automatic ATIS (Automatic Terminal Information Service) report from the sensor data — students read the ATIS aloud
