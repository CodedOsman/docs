# 2.12.2 Water Bottle Variable Testing

## Step-by-Step Assembly (Continued)

**Lesson 2 – Variable Testing**

|  |  |
| --- | --- |
| **STEP 3** | **Water Fill Variable (Rows 2–3)** |
|  | * Keep all other variables at baseline; change only the water fill level * Row 2: 15% fill — observe shorter powered phase; rocket 'runs out of steam' faster * Row 3: 50% fill — observe heavy rocket; less air volume; different thrust curve * Which fill level gives the most height? Record and note |

|  |  |
| --- | --- |
| **STEP 4** | **Launch Angle Variable (Rows 4–5)** |
|  | * Restore 30% water fill; vary only the launch angle * Row 4: 75° (nearly vertical) — maximises height; minimises horizontal distance * Row 5: 45° (classic projectile angle) — maximises horizontal range; moderate height * Discuss: for a real rocket launching a satellite, what angle is used and why? |

|  |  |
| --- | --- |
| **STEP 5** | **Fin Variable (Rows 6–7)** |
|  | * Row 6: Replace standard fins with the oversized set (double the area) * Observe: more stable flight; possibly reduced height due to added drag * Row 7: Remove all fins entirely * WARNING: confirm area is clear; finless rockets may travel in unpredictable directions * Observe: immediate spin and tumble — no fin stability |

|  |  |
| --- | --- |
| **STEP 6** | **Pressure Variable (Rows 8–9)** |
|  | * Row 8: Reduce to 50 PSI (approximately 40 pump strokes) * Row 9: Maximum 80 PSI (approximately 80 pump strokes) * Compare height and distance; identify the relationship between pressure and performance |
