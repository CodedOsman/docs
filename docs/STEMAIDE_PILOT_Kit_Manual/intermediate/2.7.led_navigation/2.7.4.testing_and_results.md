# 2.7.4 Led Navigation Testing And Results

## Engineering Principles
Learn more about the theory and principles in [Engineering Principles](../../Appendices/Engineering_Principles.md#2-7-led-navigation).

## Test Verification Table

| **Test** | **Method** | **Expected Result** | **Pass?** |
| --- | --- | --- | --- |
| **Port LED steady** | Power on ESP32; observe left wing | Red LED illuminated continuously |  |
| **Starboard LED steady** | Power on; observe right wing | Green LED illuminated continuously |  |
| **Tail LED steady** | Power on; observe tail | White LED illuminated continuously |  |
| **Strobe flashing** | Power on; count flashes in 60 s | 38–42 flashes per minute |  |
| **Landing light switch** | Flip CH6 on transmitter | White nose LED activates/deactivates |  |
| **Night orientation test** | Power on in darkened room | Can identify aircraft nose from 5 m by light colours |  |


## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| All 5 LEDs wired | Correct GPIO; correct resistor; correct colour on correct wing |
| Steady lights operate | Port red, starboard green, tail white all illuminate on power-on |
| Strobe flashing | Anti-collision strobe flashes at 38–42 flashes per minute |
| Landing light switchable | CH6 on transmitter activates/deactivates landing light |
| Night orientation passed | Aircraft nose direction correctly identified from 5 m in low light |
| Wiring diagram complete | Labelled diagram showing all 5 LEDs, resistors, GPIOs, and power rails |

## Upgrade & Extension Ideas

* PWM Dimming: add a sunrise/sunset effect where all lights gradually dim and brighten using PWM analogWrite
* Taxi Light: add a lower-power white LED under the nose for ground movement illumination
* Formation Light: add a blue LED array under the fuselage for formation flying identification at night
* Bluetooth Control: use the ESP32 Bluetooth module to control individual lights from a phone app
* Real ICAO Flash Pattern: program the more complex ICAO-specified double-flash strobe pattern
