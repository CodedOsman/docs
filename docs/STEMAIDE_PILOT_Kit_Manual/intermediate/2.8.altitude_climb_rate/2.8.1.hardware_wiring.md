# 2.8.1 Altitude Climb Rate Hardware Wiring

## Overview

The altimeter and vertical speed indicator (VSI) are two of the six basic T-scan instruments in every aircraft cockpit. In this project, students install a BMP280 barometric pressure sensor on the Project 11 RC aircraft and log altitude and vertical speed to a MicroSD card during flight. After landing, they download the CSV file and graph the complete flight profile — seeing their takeoff, climb, cruise, descent, and landing phases as data for the first time. This mirrors exactly what flight data engineers do when they review an aircraft's on-board parameter recorder.

## Step-by-Step Assembly

**Lesson 1 – Hardware Wiring**

|  |  |
| --- | --- |
| **STEP 1** | **Wire the BMP280 (I2C)** |
|  | * BMP280 VCC → ESP32 3.3V; GND → GND * BMP280 SDA → GPIO 21; SCL → GPIO 22 * Run I2C scanner sketch: confirm BMP280 detected at address 0x76 or 0x77 * Open Serial Monitor; upload BMP280 example sketch; confirm altitude and temperature readings |

|  |  |
| --- | --- |
| **STEP 2** | **Wire the MicroSD Module (SPI)** |
|  | * MicroSD VCC → 3.3V; GND → GND * MOSI → GPIO 23; MISO → GPIO 19; SCK → GPIO 18; CS → GPIO 5 * Insert formatted FAT32 MicroSD card * Upload SD card test sketch; confirm 'SD card initialised' in Serial Monitor * Verify: a test file is created on the SD card and can be read on a computer |

|  |  |
| --- | --- |
| **STEP 3** | **Mount Electronics on Aircraft** |
|  | * Place ESP32 + BMP280 + SD module in the fuselage bay (where the battery sits when not flying) * The BMP280 sensor must have access to outside air — create a 3 mm vent hole in the fuselage * Secure all components with double-sided foam tape * Route the USB programming port to an accessible position on the fuselage side |
