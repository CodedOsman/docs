## Test Verification Table

| **Test** | **Method** | **Expected Result** | **Pass?** |
| --- | --- | --- | --- |
| **BMP280 reads altitude** | Power on; check Serial Monitor | Altitude displayed in metres; updates every 500 ms |  |
| **Altitude change** | Carry unit up one flight of stairs (approx. 3 m) | Altitude increases by 2–4 m |  |
| **VSI reads climb** | Raise unit quickly 1 m in 1 second | VSI shows approx. +1.0 m/s |  |
| **VSI reads descent** | Lower unit quickly 1 m in 1 second | VSI shows approx. –1.0 m/s |  |
| **SD card logging** | Power on; fly; remove SD card; open CSV | File exists; altitude and VSI columns populated |  |
| **Graph produced** | Import CSV to spreadsheet | Altitude and VSI graphed vs. time; phases identifiable |  |


## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| BMP280 wired | Reads altitude and temperature in Serial Monitor before flight |
| SD card logging | CSV file created during flight; all rows populated |
| Graph created | Altitude vs. time graphed; takeoff, cruise, descent phases visible |
| VSI calculated | Vertical speed column correct: (Alt\_now – Alt\_prev) / time\_step |
| Density altitude calculated | Post-flight formula applied; result compared to indicated altitude |
| Analysis written | Student identifies the highest altitude, maximum climb rate, and landing phase from the data |

## Upgrade & Extension Ideas

* Multi-Flight Log: modify code to create a new file (FLIGHT002.CSV, FLIGHT003.CSV etc.) on each power-up; compare multiple flights
* GPS Altitude Comparison: add the NEO-6M GPS from Project 9; log GPS altitude alongside barometric altitude; compare the two
* Temperature Lapse Rate: graph temperature vs. altitude from the log; calculate the actual lapse rate and compare to ISA standard (–2°C per 1000 ft)
* OLED Real-Time Display: combine with Project 9 OLED display; show live altitude and VSI during flight
* Density Altitude Alert: program an LED warning that activates when calculated density altitude exceeds a set threshold
