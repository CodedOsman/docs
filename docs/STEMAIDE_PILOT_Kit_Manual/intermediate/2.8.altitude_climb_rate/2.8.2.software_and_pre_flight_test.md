# 2.8.2 Altitude Climb Rate Software And Pre Flight Test

## Step-by-Step Assembly (Continued)

**Lesson 2 – Software & Pre-Flight Test**

|  |  |
| --- | --- |
| **STEP 4** | **Upload the Flight Logger Code** |
|  | * Open the flight\_logger.ino sketch from Kit 9 USB drive * Review the code: setup creates a new file (FLIGHT001.CSV); loop reads BMP280 every 500 ms * Logged columns: Timestamp (ms), Altitude (m), Temperature (°C), Vertical Speed (m/s) * Vertical speed is calculated as: VSI = (altitude\_now – altitude\_prev) / (time\_now – time\_prev) × 1000 * Upload; carry unit up and down one flight of stairs; check CSV file for realistic values |

|  |  |
| --- | --- |
| **STEP 5** | **Calibration** |
|  | * Place the aircraft outdoors in still air for 60 seconds before each flight * This allows the BMP280 to settle to ambient pressure — the starting altitude becomes 0 m (relative) * In the code, subtract the initial pressure reading from all subsequent readings to get relative altitude * Confirm: altitude reads 0.0 m (±0.3 m) when stationary on the ground |

**Lessons 3–4 – Flight, Download & Analysis**

|  |  |
| --- | --- |
| **STEP 6** | **Flight & Data Collection** |
|  | * Power on the logger at least 60 seconds before takeoff to allow sensor settling * Fly a normal circuit: takeoff → climb to 20 m → level flight → descent → landing * Power off immediately after landing; remove the MicroSD card * Copy FLIGHT001.CSV to the classroom computer |

|  |  |
| --- | --- |
| **STEP 7** | **Data Analysis & Graphing** |
|  | * Open the CSV in a spreadsheet; inspect the first 5 rows * Create a line graph: x-axis = Time (s); y-axis 1 = Altitude (m); y-axis 2 = VSI (m/s) * Label on the graph where you can see: takeoff, climb, cruise, descent, landing * Identify: what was the maximum altitude? What was the highest climb rate (m/s)? * Calculate density altitude using the formula in Section 5 |
