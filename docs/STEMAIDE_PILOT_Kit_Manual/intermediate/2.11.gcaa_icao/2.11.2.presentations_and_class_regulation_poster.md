# 2.11.2 Gcaa Icao Presentations And Class Regulation Poster

## Step-by-Step Assembly (Continued)

**Lesson 2 – Presentations & Class Regulation Poster**

|  |  |
| --- | --- |
| **STEP 4** | **Group Presentations** |
|  | * Each group presents their Annex (4 minutes maximum) * Every group member speaks for at least 45 seconds * Class can ask one question per group * Teacher scores using the assessment criteria in Section 7 |

|  |  |
| --- | --- |
| **STEP 5** | **Class Regulation Poster** |
|  | * Combine all group posters into a single A1 class regulation map * Centre: Ghana map showing GCAA, Kotoka Airport, GACL * Surround with the 6 organisations and 6 Annexes; connect with arrows showing relationships * Display permanently in the aviation classroom as a reference |

|  |  |
| --- | --- |
| **STEP 6** | **ICAO Annex Quiz** |
|  | * 10-question quiz: teacher reads a scenario; students identify which Annex applies * Example: 'A pilot was flying without a valid medical certificate — which Annex covers this?' (Annex 1) * Example: 'An aircraft's navigation lights were the wrong colour — which Annex? (Annex 2)' * Pass mark: 80% (8 out of 10 correct) |
