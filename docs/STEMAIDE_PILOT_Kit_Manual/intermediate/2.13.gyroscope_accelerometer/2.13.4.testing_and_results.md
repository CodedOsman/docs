## Data Table

| **Motion Applied** | **Pitch (°)** | **Roll (°)** | **Yaw Rate (°/s)** | **Lateral G** | **Notes** |
| --- | --- | --- | --- | --- | --- |
| **Flat level on table** |  |  |  |  | Should all read zero or near-zero |

## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| MPU6050 wired | Reads pitch, roll, and yaw rate in Serial Monitor; no zeros across all axes |
| Serial Plotter showing | Live graphs for pitch, roll, and yaw rate plotting in real time |
| Instrument table completed | All 5 instruments described with axis, sensor, and display output |
| Data table completed | All 7 motion tests recorded with correct approximate values |
| Complementary filter applied | Pitch and roll smooth (no noise) and drift-free after filter implementation |
| Real instrument link explained | Student correctly maps each MPU6050 output to its cockpit instrument equivalent |

## Upgrade & Extension Ideas

* Graphical Attitude Indicator: draw a pitch-and-roll display on the SSD1306 OLED from Project 9 — a moving horizon line
* Accelerometer-only stall detector: when AccZ drops below 0.7g during motion, trigger a buzzer alert — this simulates a basic g-force stall warning
* Vibration Analysis: mount the MPU6050 on the Project 10 drone motor; plot AccZ at different throttle levels — identify the resonance frequency of the frame
* Kalman Filter: implement a Kalman filter instead of the complementary filter; compare noise and drift performance
