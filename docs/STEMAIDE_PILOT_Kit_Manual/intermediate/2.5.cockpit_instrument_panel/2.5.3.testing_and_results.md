# 2.5.3 Cockpit Instrument Panel Testing And Results

## Engineering Principles
Learn more about the theory and principles in [Engineering Principles](../../Appendices/Engineering_Principles.md#2-5-cockpit-instrument-panel).

## Test Verification Table

| **Test** | **Method** | **Expected Result** | **Pass?** |
| --- | --- | --- | --- |
| **I2C Scan** | Run I2C scanner sketch | All 3 I2C sensors detected at correct addresses |  |
| **BMP280 Altitude** | Carry unit up one flight of stairs | Altitude increases by ~3 m |  |
| **MPU6050 Attitude** | Tilt board 30° in pitch | Pitch reading changes to ~30° |  |
| **QMC5883L Heading** | Rotate board to face North | Heading reads 0° (±15°) |  |
| **GPS Fix** | Take unit outdoors for 60 s | Latitude/longitude displayed; speed > 0 |  |
| **Variometer** | Raise unit quickly 1 m | Positive climb rate displayed |  |
| **TFT Display** | Power on | All 5 instruments visible; no blank sections |  |
| **Full Integration** | Walk 10 m outdoors | All readings update simultaneously |  |


## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| All 4 sensors wired | I2C scan confirms all 3 I2C sensors at correct addresses; GPS parses data |
| TFT displays all instruments | All 5 instruments visible simultaneously on the faceplate |
| Altitude responds | BMP280 altitude changes when unit is raised or lowered |
| Attitude responds | Pitch and roll update correctly when board is tilted |
| Heading responds | Compass heading changes when board is rotated; calibrated to < 15° error |
| GPS fix acquired | Latitude, longitude, and speed displayed outdoors within 90 seconds |
| Panel mounted | All components secured on faceplate; wiring tidy and labelled |
| Wiring diagram submitted | Complete, colour-coded, labelled diagram signed off by teacher |

## Upgrade & Extension Ideas

* SD Card Data Logger – Add a MicroSD module; log all instrument readings with GPS timestamp to a CSV file for post-flight review
* Audio Alerts – Add a buzzer or speaker; trigger alerts when altitude drops below a threshold or attitude exceeds limits
* Graphical Attitude Ball – Draw a filled circle on the TFT that rolls and pitches as a physical artificial horizon indicator
* Moving Map Display – Use GPS coordinates to draw a simple dot-on-grid position map on a section of the TFT
* Wireless Telemetry – Use the ESP32 Wi-Fi to broadcast instrument data to a browser on a local network
* Battery Voltage Monitor – Add a voltage divider circuit to display remaining battery level on the panel
