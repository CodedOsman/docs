# 2.10.3 Jet Engine Principles Testing And Results

## Engineering Principles
Learn more about the theory and principles in [Engineering Principles](../../Appendices/Engineering_Principles.md#2-10-jet-engine-principles).

## Expected Result

| **Outcome** | **Success Criteria** |
| --- | --- |
| Brayton cycle diagram | All 5 stages labelled with correct temperature and pressure trends |
| Thermodynamic worksheet | Thrust and efficiency calculations completed with correct values |
| Rocket assembled | Bottle, nose cone, and 4 fins structurally complete and symmetrical |
| 3 launches completed | Variable changed between each launch; data recorded for all 3 |
| Best configuration identified | Highest-altitude configuration identified and explained |
| Newton's Third Law demonstrated | Student explains rocket thrust using action-reaction terminology |


## Troubleshooting
For common errors and troubleshooting, please refer to [Troubleshooting](../../Appendices/Troubleshooting.md#2-10-jet-engine-principles).

## Upgrade & Extension Ideas

* Multi-Stage Rocket: connect two bottles with a coupling; stage-separation mechanism using a rubber band release
* Payload Camera: tape a small action camera to the rocket; record the launch video; calculate height from video frame rate
* Pressure Gauge: add a pressure gauge to the launch rig; record exact launch pressure and compare to altitude
* Turbofan vs. Turbojet: extend the worksheet to compare bypass ratio effects on thrust and fuel efficiency
